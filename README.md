# 💵 Mortgage Calculator — Калькулятор ипотеки на Vue.js

Современный SPA-калькулятор аннуитетных платежей с визуализацией и экспортом данных. Разработан для демонстрации возможностей Vue 3, работы с реактивностью и лучших практик фронтенд-разработки.

## 🌐 Демо

🔗 [Калькулятор ипотеки (Vercel)](https://mortgage-calculator-vuejs.vercel.app/)

Проект деплоится через Vercel CI/CD: сборка запускается автоматически при каждом пуше в `main`. Папка `dist` не хранится в Git — она генерируется в облаке, поэтому репозиторий остаётся чистым.

## ✨ Особенности

- **Несколько уровней представления данных** — пользователь получает ровно столько информации, сколько нужно прямо сейчас: главное число → превью → график → таблица → CSV
- **Мгновенное обновление** — реактивное состояние Vue 3 пересчитывает все значения при любом изменении входных данных
- **Визуализация структуры платежа** — мини-график показывает, какая часть платежа уходит на проценты, а какая — на тело кредита
- **Практический экспорт** — кнопка «Скачать CSV» формирует готовый файл для Excel или отправки в банк
- **Адаптивность** — корректно отображается на всех устройствах, включая мобильные экраны

## 🎯 Возможности

- 🧮 Расчёт ежемесячного аннуитетного платежа по формуле
- 📉 Отображение общей переплаты за весь срок кредита
- 📊 Мини-график структуры платежа (проценты vs тело кредита)
- 📋 Детализированная таблица первых 15 месяцев графика платежей
- 📥 Экспорт полного графика платежей в CSV-файл
- 📱 Адаптивная вёрстка и плавные переходы между состояниями

## 🛠️ Стек технологий

- **Vue 3** — прогрессивный JavaScript-фреймворк с Composition API и `<script setup>`
- **Vite** — быстрый сборщик проектов с горячей перезагрузкой (HMR)
- **CSS3** — стилизация, Flexbox, адаптивность и простые анимации
- **Vercel** — хостинг и CI/CD для автоматического деплоя
- **Git** — чистая история коммитов с осмысленными сообщениями (feat, refactor, docs)

## 📁 Структура проекта

```
src/
├── components/
│ ├── InputGroup.vue # Компонент группы полей ввода (сумма, ставка, срок)
│ ├── PaymentChart.vue # Компонент мини-графика структуры платежа
│ └── PaymentTable.vue # Компонент таблицы первых 15 месяцев
├── utils/
│ ├── formatCurrency.js # Утилита для форматирования чисел в денежный формат
│ └── generateCsv.js # Утилита для генерации CSV-файла
├── App.vue # Основной компонент (шаблон + логика + стили)
└── main.js # Точка входа приложения
```

## 🚀 Быстрый старт

```bash
# Клонирование репозитория
git clone https://github.com/AndreiZhiburtovich/mortgage-calculator-vuejs.git

# Переход в папку проекта
cd mortgage-calculator-vuejs

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Открыть в браузере
# http://localhost:5173
```

## 📦 Сборка для продакшена

```bash
npm run build
```

Готовые оптимизированные файлы будут в папке dist/.

⚠️ Папка dist не хранится в Git — она генерируется автоматически при деплое на Vercel. Это сохраняет репозиторий чистым и гарантирует, что на сайте всегда актуальная версия.
